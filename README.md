# Mastery Lab

Mastery Lab 是一个面向开发者的自动导航学习框架。它把“今天该学什么、该练什么、练得对不对”收敛到一个当前任务里。

你不需要先研究课程结构，也不需要在资料里挑下一篇文章。告诉它你今天想继续学什么，它会准备任务、验证结果，并根据表现修正后面的路线。

```bash
./mastery start "继续学习 Ruby"
./mastery check
./mastery next
```

## 它解决什么

很多学习工具把重点放在内容供给上：更多视频、更多文章、更多路线图。真正的问题往往不是资料不够，而是不知道今天该练什么，不知道自己做对没有，也不知道下一步该补哪里。

Mastery Lab 把学习过程收敛成一个闭环：

```text
意图 -> 当前任务 -> 动手解决 -> 自动验证 -> 更新路线 -> 下一任务
```

你只面对当前任务。路线图、任务生成、验证记录和自适应调整由系统维护。

## 怎么开始

当前原型内置 Ruby 路线。

```bash
./mastery start "继续学习 Ruby"
```

系统会生成 `current_task/`。进入任务目录后按说明修改代码，然后回到根目录运行：

```bash
./mastery check
```

通过后进入下一关：

```bash
./mastery next
```

如果没有通过，不需要换教程。继续修当前任务，再运行 `./mastery check`。系统会记录失败点，并在路线图里调整后续练习。

## 你需要关心什么

- `./mastery`：你的本地教练，负责开始、验证和推进。
- `roadmap.md`：会变化的学习路线，会随着验证结果更新。
- `current_task/`：当前唯一练习区，由 `mastery` 自动创建。

其余内容是内部引擎和题库。你不需要理解它们，除非你要扩展新的学习路线。

## 当前任务是什么样

运行 `start` 后，`current_task/` 会包含：

```text
current_task/
  GOAL.md          本关目标，只看这一页也能开始
  README.md        场景、约束和验证方式
  workspace/       你真正写代码的地方
  verify.sh        当前任务的验证脚本
```

`current_task/` 是生成目录，不会提交到 git。完成一关后，`mastery next` 会刷新它。

## 当前状态

这是开源原型，不是完整商业产品。它已经具备三个关键能力：

- 根据一句学习意图创建或继续任务。
- 用自动化测试验证真实代码结果。
- 根据通过、失败和重试次数更新学习路线。

商业化方向很清晰：把本地状态扩展为长期技能画像，把题库扩展为真实工程场景库，把验证结果变成比“看过课程”更可靠的掌握证据。

## 贡献任务

想贡献新的语言或练习任务，读 [CONTRIBUTING.md](CONTRIBUTING.md)。原则很简单：不要让用户理解题库结构，只让用户面对当前任务。
