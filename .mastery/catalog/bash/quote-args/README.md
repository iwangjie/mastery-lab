# 任务：安全处理命令参数

很多 shell 脚本在正常输入下能跑，一遇到空格、通配符或特殊字符就出错。这个任务很小，但它考察的是 shell 自动化里最常见、也最危险的基本功：参数引用。

## 你要完成什么

请修改：

```text
workspace/bin/quote_args.sh
```

脚本应该把收到的每个参数原样输出，每个参数一行。

示例：

```bash
./quote_args.sh "hello world" "asterisk * stays"
```

应输出两行，而不是把第一个参数拆成两个词，也不是把 `*` 展开成文件列表。

## 约束

- 使用 bash。
- 不要把测试里的具体字符串写死。
- 不要依赖当前目录下是否有某些文件。

## 验证

回到项目根目录运行：

```bash
./mastery check
```
