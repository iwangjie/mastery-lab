# 问题拆解索引

问题拆解连接 `topics/` 和 `problems/`。

它不直接提供可运行现场，而是解释一个掌握场景的设计意图：

- 训练哪个能力节点。
- 不训练哪些无关能力。
- 真实失败现场是什么。
- 学习者容易怎么错。
- 验证证据为什么足够。
- 下一轮如何升级。

如果 `problems/` 是训练场，`breakdowns/` 就是训练设计说明。
